## 2026-10-20 补充：界面、性能与开发工具

改动与对应验证（均未使用个人文献或账号）：

- **深色模式插件 1.0.3**：MutationObserver 只响应新的样式表链接与排版菜单。jsdom 测试（`tests/js`）模拟 300 段流式回答插入：1.0.2 每个动画帧整体刷新一次，1.0.3 为 0 次；排版菜单仍注入主题选择，切换与卸载正常。尚未在 Zotero GUI 中人工复核。
- **XPI 工具**：`tools/plugin_xpi.py check` 确认四个 XPI 与 `src/plugins` 逐字节一致；同一源码两次 `build` 得到同一 SHA-256。
- **翻译进度面板**：在内置浏览器中用合成任务检查：文件名/错误信息中的 HTML 按文本显示；带单引号的文件名可预览；运行中任务计时逐秒更新（旧版计时器绑定在被替换的节点上，一直显示“计算中...”）；深浅色、Esc 关闭预览均正常。
- **SSE**：任务无变化时不再推送，空闲 15 秒发送保活注释；任务快照在锁内复制，避免序列化时与工作线程并发修改。新增 `test_task_events.py`。
- **公式预处理**：PyMuPDF 预筛页面，新增测试确认预筛与逐页解析结果相同；300 页合成文档 5.68 秒 → 1.55 秒。
- **脚本**：在临时副本中实际执行 `Setup.ps1 -SkipPython`、`Start-Zotero.ps1`（启动、复用已运行服务、`-StopServerOnExit`）与 `Stop-Translation.ps1`，结束后无残留 Python 进程。该机器上服务就绪约需 30 秒，超过旧版固定的 15 秒等待。
- Python 测试 23 项通过（未安装 pydantic 时健康探针测试自动跳过）；隐私扫描通过。
