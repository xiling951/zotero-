# 隐私与发布约定

本仓库只接收软件、示例配置、方案与合成测试数据。发布采用白名单，不直接压缩现用 Zotero 根目录。

禁止上传：现用 profile、library、storage、文献、笔记与批注数据库、聊天、历史、解析缓存、译文、截图、日志、Cookie、登录/同步信息、API Key、MinerU Token、私有服务地址及本机个人路径。

插件的 prefs.js 仅保留 XPI 内的出厂默认值，不能替换为个人配置目录的 prefs.js。配置文件只保留 `.example`；真实配置由首次启动在本机创建。

发布前扫描 Git 文件、解包插件、嵌套 ZIP/XPI 及 Release 内容。检测凭证特征、个人路径、数据文件名，并在本机将候选发布文件与现用配置中的敏感值比对；敏感值只在内存使用，不写入报告。报告仅包含计数和通过状态。

上游许可证里的作者署名、项目邮箱和公开网址属于软件来源信息，应保留，不将其误当成本用户个人资料。

不沿用本机私人 Git 作者邮箱；使用项目发布身份与 GitHub noreply 邮箱。发现泄露时，先撤销凭证，再删除资产并按 GitHub 流程清理历史，不能认为仅删最新文件就已解决。
